# Rental Mobil WP v1.2.0

## Deskripsi
Rental Mobil WP adalah plugin WordPress yang dirancang khusus untuk bisnis rental mobil. Plugin ini memungkinkan Anda menampilkan daftar kendaraan, detail kendaraan, dan sistem booking yang terintegrasi dengan WhatsApp.

## Fitur Baru di v1.2.0
- **Harga Fleksibel**: Tambahkan harga sewa harian, mingguan, dan bulanan untuk setiap kendaraan
- **Tampilan Responsif**: Perbaikan tampilan untuk perangkat mobile dengan floating filter button
- **URL yang Lebih Baik**: Perubahan slug halaman detail dari `/kendaraan/` menjadi `/rental/`
- **Layout Full Width**: Tampilan daftar kendaraan dengan layout fullwidth

## Cara Upgrade
1. Nonaktifkan versi lama plugin
2. Hapus versi lama plugin
3. Upload dan aktifkan versi baru plugin
4. Kunjungi halaman Settings > Permalinks dan klik "Save Changes" untuk memperbarui rewrite rules

## Catatan Penting
- Pastikan untuk memperbarui permalink setelah upgrade untuk memastikan perubahan slug berfungsi dengan baik
- Jika Anda telah melakukan modifikasi pada file plugin, pastikan untuk backup sebelum upgrade

## Kompatibilitas
- WordPress 5.0 atau lebih baru
- PHP 7.2 atau lebih baru
- Kompatibel dengan tema Divi
